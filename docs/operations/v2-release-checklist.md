# V2 发布审阅清单

默认 NO-GO。此清单是可审阅包，任何真实部署另需明确授权。

- [ ] 固定代码SHA、镜像digest、JDK25、构建依赖树与迁移001—006校验和；没有未提交源代码。
- [ ] 所有预期测试非零、failures/errors/skips=0；旧演示测试已单独记录，不能宣称无筛选全套通过。
- [ ] 故障矩阵每行执行证据；真实SIGKILL、broker停机、DB连接断开、双实例接管与持续新增下恢复。
- [ ] 维护窗口全域停旧资产写、排空、原始审计期初、重复账户/旧消息/待履约身份逐项证明。
- [ ] 所有迁移DDL可重入、每表行数/金额/checksum一致；没有DROP回滚或SUM重复账户。
- [ ] CREDIT/QUOTA/STOCK/DELIVERY/PAYMENT/SIGNIN均已检查且差异0；已受理全部终态或持久核查，核查责任人明确。
- [ ] 同语义基线；四档固定到达率、热点2/8/32、签到/支付重投/版本切换/持续新增恢复；预热+每档≥600秒、关键重复3次。
- [ ] 每订单稳定ID原始记录、独立tracker、服务端完成时间/时钟校准、轮询流量另记。
- [ ] P99查询≤200ms/受理≤500ms/完成≤5s，积压不增长，拒绝率/不足迭代/压测端瓶颈均列明。
- [ ] 全部实例各逻辑连接池按物理DB聚合；保留回调/查询/恢复预算；配置扩容不超过max_connections/CPU/IO。
- [ ] 中间件持久化/副本与故障模型说明；隔离单节点不能证明副本整体丢失恢复。
- [ ] 凭据不进git；沙盒只test/local-sandbox；真实渠道/退款不在首版。
- [ ] 停止/恢复点和操作人签字；保留V2 Worker排空，不把V2中间状态交回旧实现。
